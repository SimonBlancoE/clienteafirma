# son los datos que se insertan. En los textos largos, una línea que empieza por «## » es un

# App» y «Autofirma» se escriben «AutoFirma». Las correcciones de las erratas del original

response_1 = AutoFirma allows you to sign with certified web formalities compatible with the application. To sign a paperwork, please complete it normally through your web browser. If the procedure is ready for signature with AutoFirma, it will be executed at the time of signature, will allow the user to select the signing certificate and run the operation.\n\nThere is also the possibility of opening the application and signing a file directly for personal use. A signature will be added to the PDF documents, while for the other files a separate signature file will be generated.\n\nRemember that in order to be able to sign before you must have imported your signature certificate on Android.

response_2 = AutoFirma still lacks certain features that are present in versions for other operating systems. Future app updates will address these shortcomings.
